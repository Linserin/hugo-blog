# Hugo-Blog
This is the source code of [Linserin Yang's Blog](https://linserin.work).

In the past, it was published on [Releases](releases) Page.

## Quick Start

Download [Hugo](https://github.com/gohugoio/hugo/releases).

### Start a Develop Server

Run command:
```shell
hugo serve
```

### Build

Run command:
```shell
hugo
```

## Used
[SourceHanSansCN](https://fonts.adobe.com/fonts/source-han-sans-simplified-chinese) and [JetBrains Mono](https://www.jetbrains.com/lp/mono/) are used in this site as fonts for articles and code display. The source code package contains the above fonts.
